# AltSchool Cybersecurity Capstone

This repository contains my cybersecurity capstone work completed as part of the AltSchool Africa Cybersecurity program.

## About the Project

The capstone demonstrates practical application of cybersecurity concepts through hands-on security assessments, testing, analysis, and documentation.

## Objectives

- Apply cybersecurity concepts in practical scenarios
- Perform security testing in controlled environments
- Identify and analyze security vulnerabilities
- Document findings and security recommendations
- Demonstrate practical cybersecurity skills

## Technologies & Tools

- Linux
- Burp Suite
- Nmap
- Wireshark
- Aircrack-ng
- Python
- SQL
- Git & GitHub

## Project Structure

The repository contains individual capstone projects, supporting documentation, screenshots, and relevant evidence of implementation.
